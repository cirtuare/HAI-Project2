④ 사용자 상호작용 흐름
A
사용자가 사용할 페르소나 지정
Chat 진입 전, 고민과 관련된 페르소나를 선택하거나 전체를 열어둠
금융 취미 + 수동 추가 가능
B
Chat 형식으로 고민 던져줌 (with Context)
사용자가 자연어로 고민을 입력 → 로컬 데이터 컨텍스트와 함께 관련 페르소나들에게 전달
"이번 주 제주도 항공권 살까?"
C
관련된 페르소나끼리 토론 진행
서로 다른 목표를 가진 페르소나들이 의견 충돌, 사용자는 제3자로 관찰
LIVE DEBATE
💰
이번 달 예산 이미 초과. 항공권은 다음 달로 미뤄야 해.
🎨
메모에 적어뒀던 여행 아이디어잖아. 지금 아니면 또 미뤄.
D
토의/론 결과 사용자 공유
각 페르소나의 논거 요약 + 최종 제안(결론이 아닌 선택지)을 사용자에게 제시
결과 요약 예시
금융: 예산 -18만원 초과 · 취미: 잔여 연차 2일 확인됨
→ "다음 주 얼리버드 노려보는 건 어때?"
